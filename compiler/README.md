# Bootstrap Compiler Tree

This directory holds the Nore-written compiler source tree.

Milestone 1 freezes the module layout and the bootstrap coding subset. Milestones 2, 3, 4, 5, and 6 now provide the committed support-library, source-management, diagnostics, token, lexer, node-table, parser, and multi-module frontend loader building blocks. Milestone 7 now includes sema tables, scope/name binding, basic subset typing for literals/fields/constructors/calls/assignments/control flow, table-column field access as slice views, statement-vs-expression `if` handling, tagged-enum payload binding plus scalar literal/wildcard `match` arms with duplicate/exhaustiveness diagnostics, the first compiler-built-in typing slice for `arena`, `arena_alloc`, `arena_reset`, `table_alloc`, `table_len`, `table_get`, and `table_insert`, native declaration validation, enum/tagged-variant construction, plain-enum comparisons/casts, typed array literals, slice/string-literal ref arguments, compiler-injected `OS` / `TARGET_OS`, expected integer literal typing in annotated contexts, local arena provenance tracking with `S053` / `S055` / `S056`, and enough loader/path normalization plus arena-safety coverage to keep transitive compiler-module type identities stable. One real compiler support module (`compiler/support/byte_buf.nore`), one real compiler sema module (`compiler/sema/check.nore`), and four real std modules (`std/string.nore`, `std/file.nore`, `std/json.nore`, `std/io.nore`) now sema-check cleanly. Milestone 8 now has six committed codegen slices: `compiler/codegen/c_types.nore` lowers sema types to stable C names and emits typedefs for arrays, slices, values, structs, tables, table rows, and enums; `compiler/codegen/c_emit_decl.nore` emits stable module-prefixed user-function signatures plus forward prototypes for both user functions and plain `ni_*` native runtime hooks, with correct ref-parameter lowering; `compiler/codegen/c_runtime.nore` emits the minimal generated-C prelude for `stdint.h`, `ni_str`, `ni_Arena`, and `ni_OS`; `compiler/codegen/c_emit_expr.nore` now lowers the broader early expression subset (literals, typed array literals, unary/binary/cast expressions, identifiers, field/index/slice access, constructors, plain user-function calls, and ref arguments over slice-view temporaries); `compiler/codegen/c_emit_stmt.nore` now lowers the broader early statement/body subset (blocks, local declarations, assignments, explicit returns, tail-value blocks, statement-form `if` / `match` / `while` with `break` / `continue`, plus value-position `if` / `match` lowered through statement codegen for returns and local initializers); and `compiler/codegen/c_main.nore` now assembles those pieces into the current whole-file C dump with stable module-global definitions for top-level `val` / `mut` bindings plus native/user prototype sections before function bodies. Those slices are covered by `tests/bootstrap/codegen/type_defs_test.nore`, `tests/bootstrap/codegen/edge_type_defs_test.nore`, `tests/bootstrap/codegen/function_prototypes_test.nore`, `tests/bootstrap/codegen/c_file_skeleton_test.nore`, `tests/bootstrap/codegen/global_defs_test.nore`, `tests/bootstrap/codegen/array_expr_test.nore`, `tests/bootstrap/codegen/match_codegen_test.nore`, `tests/bootstrap/codegen/node_module_match_codegen_test.nore`, `tests/bootstrap/codegen/compiler_module_codegen_test.nore`, `tests/bootstrap/codegen/parser_module_globals_test.nore`, and `tests/bootstrap/codegen/std_io_module_codegen_test.nore`, with the real-module smoke coverage now including one compiler support module, one compiler frontend module, one parser-module globals slice, and one real std module. The documented cross-function reset limitation remains, and fully general control-flow-as-expression lowering, polished runtime-helper expansion, and driver work still remain. See [`../docs/compiler-bootstrap-architecture.md`](../docs/compiler-bootstrap-architecture.md) for the current contract.
