# Bootstrap Compiler Tree

This directory holds the Nore-written compiler source tree.

Milestone 1 freezes the module layout and the bootstrap coding subset. Milestones 2 and 3 now provide the committed support-library, path, source, line-map, and diagnostic building blocks; later frontend, sema, codegen, and driver modules remain placeholders until their milestone starts. See [`../docs/compiler-bootstrap-architecture.md`](../docs/compiler-bootstrap-architecture.md) for the current contract.
