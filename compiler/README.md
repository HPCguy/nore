# Bootstrap Compiler Tree

This directory holds the Nore-written compiler source tree.

Milestone 1 freezes the module layout and the bootstrap coding subset. Milestones 2, 3, 4, and 5 now provide the committed support-library, source-management, diagnostics, token, lexer, node-table, and single-module parser building blocks; sema, codegen, and driver modules remain placeholders until their milestones start. See [`../docs/compiler-bootstrap-architecture.md`](../docs/compiler-bootstrap-architecture.md) for the current contract.
