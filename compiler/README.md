# Bootstrap Compiler Tree

This directory holds the Nore-written compiler source tree.

Milestone 1 freezes the module layout and the bootstrap coding subset. Milestones 2, 3, 4, 5, and 6 now provide the committed support-library, source-management, diagnostics, token, lexer, node-table, parser, and multi-module frontend loader building blocks. Milestone 7 now includes sema tables, scope/name binding, basic subset typing for literals/fields/constructors/calls/assignments/control flow, table-column field access as slice views, statement-vs-expression `if` handling, tagged-enum payload binding plus scalar literal/wildcard `match` arms with duplicate/exhaustiveness diagnostics, the first compiler-built-in typing slice for `arena`, `arena_alloc`, `arena_reset`, `table_alloc`, `table_len`, `table_get`, and `table_insert`, native declaration validation, enum/tagged-variant construction, plain-enum comparisons/casts, typed array literals, slice/string-literal ref arguments, compiler-injected `OS` / `TARGET_OS`, expected integer literal typing in annotated contexts, local arena provenance tracking with `S053` / `S055` / `S056`, and enough loader/path normalization plus arena-safety coverage to keep transitive compiler-module type identities stable. One real compiler support module (`compiler/support/byte_buf.nore`), one real compiler sema module (`compiler/sema/check.nore`), and four real std modules (`std/string.nore`, `std/file.nore`, `std/json.nore`, `std/io.nore`) now sema-check cleanly. Milestone 8 is now complete: `compiler/codegen/c_types.nore` lowers sema types to stable C names and emits typedefs for arrays, slices, values, structs, tables, table rows, and enums; `compiler/codegen/c_emit_decl.nore` emits stable module-prefixed user-function signatures plus forward prototypes for both user functions and plain `ni_*` native runtime hooks, with correct ref-parameter lowering; `compiler/codegen/c_runtime.nore` emits the generated-C prelude plus the shared arena/native/runtime-entry bodies (`ni_arena_*`, `ni_fd_*`, `ni_mem_copy`, `ni_exit`, `ni_args`), now with a strict-Clang-safe `NI_ALIGNOF(...)` helper for the bootstrap path; `compiler/codegen/c_emit_expr.nore` lowers the broader early expression subset (literals, typed array literals, unary/binary/cast expressions, identifiers, field/index/slice access, constructors, builtin `arena_*` / `table_*` calls, plain user-function calls, injected `TARGET_OS` / `OS.*` names, expected-type-aware byte-view/ref coercions, and the fixed `table_len(ref table)` precedence for local tables); `compiler/codegen/c_emit_stmt.nore` lowers the broader early statement/body subset (blocks, local declarations, assignments, explicit returns, stage-0-compatible `assert` diagnostics with `R001` and exit code 2, tail-value blocks, statement-form `if` / `match` / `while` with `break` / `continue`, plus value-position `if` / `match` lowered through statement codegen for returns and local initializers); `compiler/codegen/c_main.nore` assembles those pieces into the current whole-file C dump with stable module-global definitions for top-level `val` / `mut` bindings, runtime/helper sections, a generated C entry wrapper for zero-arg Nore `main`, per-table alloc/get/insert helpers when builtin table operations are used, and the current value-coercion helper slice before function bodies; and `compiler/driver/cli.nore` now owns the bootstrap driver's root-`main` validation (`S009` / `S010`) before codegen writes output. Those slices are covered by `tests/bootstrap/codegen/type_defs_test.nore`, `tests/bootstrap/codegen/edge_type_defs_test.nore`, `tests/bootstrap/codegen/function_prototypes_test.nore`, `tests/bootstrap/codegen/c_file_skeleton_test.nore`, `tests/bootstrap/codegen/global_defs_test.nore`, `tests/bootstrap/codegen/array_expr_test.nore`, `tests/bootstrap/codegen/assert_stmt_test.nore`, `tests/bootstrap/codegen/builtins_codegen_test.nore`, `tests/bootstrap/codegen/byte_view_coercion_codegen_test.nore`, `tests/bootstrap/codegen/byte_view_storage_codegen_test.nore`, `tests/bootstrap/codegen/compiler_main_codegen_test.nore`, `tests/bootstrap/codegen/compiler_main_validation_test.nore`, `tests/bootstrap/codegen/compiler_module_codegen_test.nore`, `tests/bootstrap/codegen/entrypoint_codegen_test.nore`, `tests/bootstrap/codegen/match_codegen_test.nore`, `tests/bootstrap/codegen/node_module_match_codegen_test.nore`, `tests/bootstrap/codegen/parser_module_globals_test.nore`, `tests/bootstrap/codegen/std_io_module_codegen_test.nore`, and `tests/bootstrap/codegen/std_file_module_codegen_test.nore`. Milestones 9 and 10 are now complete: `compiler/main.nore` is the committed graph-load/typecheck/emit pipeline, `tests/run_bootstrap_tests.sh` is the dedicated bootstrap runner, `tests/bootstrap/selfhost/smoke_test.sh` proves the stage-0 -> bootstrap compiler -> generated C -> Clang flow for `tests/success/print_hello.nore` and `tests/success/args.nore`, and `tests/bootstrap/selfhost/self_compile_test.sh` proves the stage-0 -> `nore1` -> `nore2` -> `nore3` self-compile chain with identical stage-2/stage-3 generated C. See [`../docs/compiler-bootstrap-architecture.md`](../docs/compiler-bootstrap-architecture.md) for the current contract.
