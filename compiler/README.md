# Bootstrap Compiler Tree

This directory holds the Nore-written compiler source tree.

Milestone 1 freezes the module layout and the bootstrap coding subset. Milestones 2, 3, 4, 5, and 6 now provide the committed support-library, source-management, diagnostics, token, lexer, node-table, parser, and multi-module frontend loader building blocks. Milestone 7 now includes sema tables, scope/name binding, basic subset typing for literals/fields/constructors/calls/assignments/control flow, table-column field access as slice views, statement-vs-expression `if` handling, tagged-enum payload binding plus scalar literal/wildcard `match` arms with duplicate/exhaustiveness diagnostics, the first compiler-built-in typing slice for `arena`, `arena_alloc`, `arena_reset`, `table_alloc`, `table_len`, `table_get`, and `table_insert`, native declaration validation, enum/tagged-variant construction, plain-enum comparisons/casts, typed array literals, slice/string-literal ref arguments, compiler-injected `OS` / `TARGET_OS`, expected integer literal typing in annotated contexts, local arena provenance tracking with `S053` / `S055` / `S056`, and enough loader/path normalization plus arena-safety coverage to keep transitive compiler-module type identities stable. One real compiler support module (`compiler/support/byte_buf.nore`), one real compiler sema module (`compiler/sema/check.nore`), and four real std modules (`std/string.nore`, `std/file.nore`, `std/json.nore`, `std/io.nore`) now sema-check cleanly. The documented cross-function reset limitation remains, but Milestone 7 is now closed; codegen/driver modules remain for later milestones. See [`../docs/compiler-bootstrap-architecture.md`](../docs/compiler-bootstrap-architecture.md) for the current contract.
