## The Name

Nore comes from [NOR](https://en.wikipedia.org/wiki/NOR_gate), one of the fundamental logic gates. NOR is a [universal gate](https://en.wikipedia.org/wiki/NOR_gate#Functional_completeness), meaning any logical function can be built from NOR alone. The name reflects the language's philosophy: build complex systems from simple, composable primitives.

## The Symbol

The **|~|** symbol in the logo represents the capital letter N by combining **~** (NOT) and **|** (OR), the two operations that form NOR.

## The Color

The indigo color pays tribute to the [SGI Indigo](https://en.wikipedia.org/wiki/SGI_Indigo), a workstation that shaped the history of computer graphics and high-performance computing.
