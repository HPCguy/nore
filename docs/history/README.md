# Historical Documents

This directory preserves milestone-era planning and architecture notes from the bootstrap and self-hosting phase of the project.

These documents remain useful as project history, but they no longer describe the canonical current structure of the compiler or repository.

- [self-hosting-bootstrap-plan.md](self-hosting-bootstrap-plan.md) records the bootstrap plan that led to the `selfhost-parity` milestone.
- [compiler-bootstrap-architecture.md](compiler-bootstrap-architecture.md) is the frozen Milestone 1 architecture note for the bootstrap compiler.

For the current compiler documentation, see [../compiler.md](../compiler.md) and [../compiler-architecture.md](../compiler-architecture.md).
